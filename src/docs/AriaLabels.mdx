## Architecture & Styling Rules

* Explicit String Values: Setting state properties via JavaScript requires explicit string values rather than raw booleans. Example: Right: `elem.ariaExpanded = "true"` Wrong: `elem.ariaExpanded = true`
* Tailwind CSS Integration: Hook directly into these standardized states using Tailwind's built-in modifiers instead of redundant custom selectors. Example: Right: `aria-expanded:block` Wrong: `data-[expanded]:block`
